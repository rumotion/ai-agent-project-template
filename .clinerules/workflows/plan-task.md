# Workflow: Plan Task

Use this workflow when the user asks to plan a feature, fix, refactor, or automation.

Steps:

1. Read `AGENTS.md`.
2. Read `memory-bank/00-index.md`.
3. Read relevant Memory Bank files.
4. Inspect relevant source files.
5. Produce a plan with:
   - Goal
   - Requirements
   - Assumptions
   - Proposed approach
   - Affected files
   - Risks
   - Test plan
   - Rollback plan where relevant
   - Memory Bank updates
6. Do not edit files until the user approves if the task is high-risk or ambiguous.
