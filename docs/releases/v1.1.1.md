# v1.1.1 - Completion-first agent pacing

Fixes pacing recommendations that could start more agents while unfinished
work accumulated.

- Requires a fresh task board before recommending new work. Defaults to one
  worker and at most two open tasks.
- Reserves time and quota for the whole required work package, including
  dependent checks and integration, with a 50% estimate margin.
- Pauses new dispatch while results await acceptance, tasks are blocked or
  lead context reaches 75%. Dependencies release after parent verification.
- Expands offline regression coverage from 18 to 34 tests.

Pacing stays opt-in and advisory. Process launching, file leases and automatic
cancellation still need a native supervisor.
