# v1.2.0 - Upgrade existing projects from your template

You can now bring the AI agent framework into your own existing projects, or
update projects created from an older template. Use a template source on GitHub
or GitLab. The upgrader previews changes, records the source commit, creates
external backups and preserves local conflicts for review. Application code,
active settings and existing project memory stay under project control.

Open the project in your coding agent and paste:

```text
Upgrade this project's AI framework from
https://github.com/rumotion/ai-agent-project-template using its latest upgrade
workflow. Preserve application code, tests, settings, custom rules, skills and
project memory. Preview changes, resolve conflicts and run the project's checks.
Do not push or deploy.
```

Replace the URL with your own template repository if you use a fork. After the
first remote upgrade, ask: "Update this project from its saved AI template
source and verify the result locally."

The upgrader needs Python 3.9+ and Git. Private repositories use your existing
Git authentication. Compatibility still needs project-specific checks; unresolved
conflicts are reported rather than overwritten. Downloaded code isn't executed
by the upgrader.
