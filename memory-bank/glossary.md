# Glossary

| Term | Meaning |
|---|---|
| AGENTS.md | Canonical model-agnostic instruction file for agents. |
| Adapter | Tool-specific instruction file that points back to `AGENTS.md`. |
| Memory Bank | Durable, concise project context used by AI agents. |
| Workflow | Repeatable task procedure/SOP. |
| Skill | Reusable expert procedure with YAML frontmatter for agent activation. |
| MCP | Model Context Protocol, used to connect agents to external tools/resources. |
| Karpathy-style defaults | Engineering behavior focused on clarifying assumptions, simplicity, surgical changes, and verification. |
| Lazy-load | Read detailed files only when they are relevant to the current task. |
